# Daily Piano

4/4拍子・4小節のメロディーと、1拍ごとに変わる7thコードをランダム生成するブラウザアプリです。

## 起動

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## 仕様

- 4小節（各小節4個、合計16個の4分音符）のメロディーをC4〜C6の音域で自動生成
- 1拍ごとにフラットを含まない7th・M7・m7コードを設定（シャープルートにも対応）
- コード構成音から、メロディーの1オクターブ以内にある音を伴奏音として選択
- Web Audio APIによるテンポ可変のプレビュー再生
